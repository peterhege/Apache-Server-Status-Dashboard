# Apache Server Status Dashboard

A Tampermonkey userscript that replaces the default Apache `/server-status` page with a modern, interactive dashboard.

## Features

- CPU usage and timeline
- Worker usage and timeline
- Worker state distribution
- Apache scoreboard visualization
- Server load
- Request and transfer metrics
- Process tables
- Customizable dashboard layout
- Resizable and sortable widgets
- Configurable refresh interval
- Live update toggle

## Requirements

- Apache `mod_status`
- A userscript manager such as Tampermonkey or Violentmonkey

## Installation

1. Install a userscript manager.
2. Download the latest `.user.js` file from the Releases page.
3. Open the file in your browser and install the userscript.
4. Open your Apache `/server-status` page.

## Status

This project is currently in **beta**.

Features and UI may change between releases.
